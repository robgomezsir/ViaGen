# Sistemas

## Escâner
Detecta:
- recursos
- sinais
- anomalias
- memórias

## Sobrevivência
Recursos principais:
- oxigênio
- energia
- combustível
- temperatura

## Sistema de Memória
Objetos ativam:
- lampejos do passado
- distorções
- diálogos
- cenas emocionais

## Nave
Funciona como:
- base de operações
- estação de criação
- centro de melhorias
- núcleo narrativo
