# VIA:GEN — Sistema Procedural

## Filosofia
Não gerar mundos infinitos.
Gerar mundos emocionalmente coerentes.

---

# Arquitetura

## Camada Emocional
Cada planeta nasce de uma emoção:
- luto
- esperança
- medo
- nostalgia
- culpa

## Biomas
- desertos cristalinos
- oceanos infinitos
- florestas bioluminescentes
- gravidade quebrada

## Camada Atmosférica
Controla:
- névoa
- partículas
- iluminação
- cor do céu
- tempestades

## Anomalias
- gravidade invertida
- distorções temporais
- oceanos suspensos
