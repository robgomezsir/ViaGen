
# VIA:GEN Stylized Environment

Conteúdo:
- Ground plane
- Portal structure
- Stylized rock formations

Uso recomendado:
1. Importar no Blender ou Unity.
2. Aplicar materiais emissivos roxo/ciano.
3. Adicionar:
   - volumetric fog
   - bloom
   - particle systems
   - skybox espacial
4. Utilizar URP na Unity.

Este FBX é uma base blockout inspirada no menu do jogo VIA:GEN.
